# Contradictions

Places where Oracle's agent skills, the type definitions and Oracle's documentation disagree with each other, or one disagrees with itself. A rule that depends on one cites its id (`C-001`) in its source comment. See [`README.md`](README.md) for how to verify one, and [Verified facts](../rule-priority.md#verified-facts) for what a verification can overrule.

Status is one of:

- **unverified**: nobody has run a test. The rule follows the higher-ranked source and says so.
- **verified**: a test ran. The results page explains it and records the decision.
- **not testable**: a disagreement about a recommendation, not about platform behavior, so no test can settle it. The decision is recorded here.

An open verification has a tracking issue; the umbrella is #72.
