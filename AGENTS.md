## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (`nemchik/biome-plugin-suitescript`) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## GitHub Actions

Pin every action to its commit SHA with the full semver in a trailing comment, using the latest stable release (look it up with `gh api repos/<owner>/<repo>/releases/latest`), for example `actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1`. Tool versions come from `package.json` `devEngines` (Node, npm), mirrored in `.nvmrc` and `.tool-versions`; change them in all three. The CI job that tests against the latest Biome is intentionally unpinned.

## Code

Source is TypeScript in `src/` and compiles to `dist/` (gitignored, published). `biome-manifest.json` and `configs/minimal.json`, `recommended.json` and `all.json` are generated by `npm run build` and committed. Run `npm run format` before committing; CI runs `biome ci --error-on-warnings` and `tsc`. Generated files: `biome-manifest.json`, `configs/{minimal,recommended,all}.json`, `src/lib/modules.ts` (`npm run sync-modules`).

## Rules

Before adding or changing a rule, follow `docs/rule-priority.md`: source tiers (Oracle docs, then Oracle agent skills, then SuiteScript-specific rules, then generic JavaScript), which tier wins a conflict, and default severity and preset placement. Do not add a generic JavaScript rule unless it explicitly benefits SuiteScript and Biome does not already cover it. Assume SuiteScript 2.1 only, and never document backwards compatibility overrides for 1.0, 2.0 or 2.x. Read Oracle docs and skills in full, with every referenced material, never truncated.

## Releases

Publishing uses npm trusted publishing (OIDC) from `.github/workflows/release.yml`; do not add an `NPM_TOKEN`. npm tokens that bypass 2FA lose publishing around January 2027.
